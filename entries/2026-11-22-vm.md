## What I Did
* Built a setup with the possibility to spawn agentic environments and multi-repo management on a remote Hetzner VM.
* Each repo (spawned via /spawn-repo) gets cloned and managed by a claude-rc@<repo> systemd service which opens an outbound connection Anthropic.
* Each session in there gets spawned with its own worktree. Subagents can go deeper and also get subtrees to work on.
* Access to VM is over SSH but hardened and works only througha Tailscale network (workstation + VM).
* Due to RC, coordinating work is possible on desktop app and/or phone or directly on the VM through SSH.
* A daily health check prunes old worktrees and reports Agent VM Problems as GitHub issues, may they arise.

## Key Insights
* Lots of Subagents can easily thrash the VM. So sizing and coordination is important :) Had a fun memory shortage to work with.
* Swap file helps.
* Learned a lot about Linux and OS. free, htop, vmstat, ...
